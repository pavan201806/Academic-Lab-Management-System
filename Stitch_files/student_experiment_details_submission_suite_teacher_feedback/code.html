1. Objective & Algorithmic Specifications

Implement an augmented Self-Balancing Red-Black Binary Search Tree conforming strictly to the CLRS definition. The system must maintain structural red-black invariants after successive arbitrary key insertions, execute color flips, and trigger deterministic single/double left and right rotations. Students must guarantee worst-case O(log N) lookup/insert bounds and assert zero memory leaks utilizing Valgrind memory virtualization profiling.

Rule 1 Node is Red / Black
Rule 2 Root is Always Black
Rule 3 No Adjacent Red Nodes
Rule 4 Equal Black Height
terminal

2. Required Software & Environment

GCC / G++ 11.2+ Ubuntu 22.04 LTS (x86_64) Valgrind 3.18.1+ C++17 ISO Standard
format_list_numbered

3. Step-by-Step Instructions

1

Node Allocation: Initialize leaf sentinels (T_NIL) colored Black. Ensure new insertion nodes initialize as Red.

2

BST Insertion Routine: Execute standard binary insertion based on key ordering, referencing parent pointers properly.

3

Violation Triaging: If the newly inserted node's parent is Red, assess the uncle's color bit to branch into Case 1 (Recolor) or Cases 2 & 3 (Rotations).

4

Rotation Primitives: Implement deterministic rotateLeft(Node* x) and rotateRight(Node* y) preserving sub-tree linkages.

5

Root Invariant Enforcement: Conclude insertion fixup loop by explicitly setting root color to Black (root->color = BLACK).
